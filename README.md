# 暗影幸存者 · TapTap 制造

面向闲暇短局的幸存者肉鸽。技术栈为 TapTap 制造 / UrhoX Lua 5.4；10月26日试玩反馈调整在本地完成，尚未重新提交远端构建。完整规则见 [DESIGN.md](DESIGN.md)。

## 一局怎么玩

选初始剑、弓或法杖 → 自动攻击、移动躲避并拾取材料 → 生存至本波倒计时结束 → 选择累计属性强化 → 商店购买、刷新、锁定、回收 → 下一波。已移除契印选择和相应攻击效果，保留商店武器配方进化。

8波纯战斗时长上限305秒，目标完整局约5–8分钟；购物与升级期间暂停。最后一波可击败首领提前获胜。

最多6把武器自动同时攻击，同类同级复制品可选择合成或扩充，最高4级。共鸣按 I/II/III/IV 阶计1/2/4/8点，每类上限6点，合成保留共鸣。剑在2/4/6点增加攻速，弓3点增加穿透，杖每2点增加灼烧。12种道具包含攻速/护甲、伤害/生命等取舍。剩余普通材料参与波末结转、利息与收获。

击杀蓄满8点能量后可按 E 引燃，产生清场冲击和2秒强化，恢复9秒。携宝怪限时逃走，击杀后还需靠近拾取宝箱；宝箱波末消失，普通材料仍自动结转。宝箱提供一张本局锻造券，可以在商店领取免费 I 阶武器，或完成一种配方进化，也可以留至后续波次使用。

## 本局进化核心

商店顶部会显示配方进度。持有至少 II 阶对应武器、指定遗物和一张夺宝券后，点击选择本局核心；武器与遗物保留，同类武器继承进化。每局只选一种核心，基础武器仍可混搭，重开重新选择。

| 武器与遗物 | 进化核心 | 攻击变化 |
| --- | --- | --- |
| II 阶剑 + 狂战护符 | 血月回斩 | 每3次剑出手自动周身回斩，最短间隔0.45秒 |
| II 阶弓 + 猎人镜片 | 追魂弹射 | 穿透后自动追击附近新目标，耗尽穿透再追加2跳 |
| II 阶杖 + 火种 | 余烬蔓延 | 持杖时燃烧敌人死亡，向附近最多5个目标传火 |

未确定核心时，商店第一格优先出售初始武器缺少的同类武器或配方遗物，仍消耗正常材料，已锁商品保留。玩法参考、迭代过程与验证见 [RECIPE-DESIGN.md](RECIPE-DESIGN.md)。

## 操作和启动

由你方便时在此目录运行 `./play-local.ps1` 打开可见游戏窗口。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键；触屏左侧拖动 |
| 选择初始武器 | 标题页1 / 2 / 3，或点击 |
| 开始 / 下一波 | Enter，或点击 |
| 自动攻击 | 所有已拥有武器独立冷却、自动选择射程内无遮挡目标 |
| 翻滚 | 空格 |
| 引燃 | E；8点蓄能、2秒强化、9秒恢复；也可点击按钮 |
| 旋风 / 剑气 | J / K |
| 药水 | F；一局初始2瓶，商店可补充 |
| 暂停 / 继续 | Esc / P |
| 音效开关 | M，或底部静音按钮；重开保留本次开关状态 |
| 升级选择 | 波间1 / 2 / 3，或点击 |
| 商店购买 | 1 / 2 / 3 / 4，或点击 |
| 刷新商店 | R，或点击 |
| 锁定 / 回收 | 对应商品或武器按钮 |
| 结算重开 | R，或点击 |

## 文件

- `scripts/Dungeon.lua`：碰撞、弹道、伤害和结算。
- `scripts/Survival.lua`：波次导演、六槽武器、合成、商店与经济。
- `scripts/DungeonView.lua` / `Sprites.lua`：像素角色、敌人预警、多武器和战斗效果。
- `scripts/CombatFeel.lua`：剑的蓄力、交替扫击与逐帧命中，击退、短暂硬直、粒子和连杀。
- `scripts/WeaponEvolutions.lua`：本局进化配方、回斩、追魂与传火。
- `scripts/CombatAudio.lua`：八通道限流音效；`dev/generate-combat-audio.py` 可重建三个原创合成 PCM 音效。
- `scripts/DungeonUI.lua`：倒计时、血量/经验、构筑信息与商店。
- `scripts/DungeonTheme.lua` / `DungeonScreens.lua`：统一的黑曜石、铜刻线与朱红印记界面，原生菜单与商品/奖励卡片。规范见 [UI-DESIGN.md](UI-DESIGN.md)。
- `scripts/main.lua`：引擎生命周期、键盘触屏和本地战绩。
- `scripts/qa/`：单独的受控验证入口；正式游戏入口为 `main.lua`。

## 剑攻击与战斗反馈修正

此前剑会把出生预警中的不可见敌人当成目标；现在预警期间不选敌、不受伤、不消耗穿透次数。剑改为约0.03秒蓄力、0.15秒扫击及收招，左右交替横扫；伤害随剑刃轨迹结算，一次挥动对每名敌人至多命中一次，支持扇形边缘的圆形碰撞并受墙体阻挡。刀光、剑身和判定读取同一份角度、距离与进度，刀光会在墙边截断。

初始剑伤害倍率由1提高至1.25，攻击间隔由0.66秒降至0.54秒；保持112距离，定位为近身横扫与击退。普通敌人命中时短暂硬直并后退，精英和首领抵抗击退，首领免疫此硬直。新增命中火花、击杀碎片、强调暴击数字、轻微世界震动与连杀提示；HUD固定。粒子上限240、音效池8个，密集战斗有独立声音限流。

剑专项入口为`qa/Sword.lua`，完整自动走位的剑开局入口为`qa/SwordRun.lua`。证据位于上级`artifacts/sword-feel/`，保留了修复前失败的复现。后台逐阶段调用实际绘制函数只能检查代码路径，不能证明最终画面或手感。
